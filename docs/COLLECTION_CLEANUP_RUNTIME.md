# 수집 후 자동 정리 실행 계약

## 목적

자동 정리는 새 출처 수집이 성공하기 전에 오래된 보존 데이터를 먼저 삭제하지 않습니다. 화면 수동 수집, 예약 수집, 대시보드 백그라운드 수집과 `python scripts/refresh_trends.py` 직접 실행이 같은 정리 경계를 사용합니다.

## 실행 순서

정리가 활성화되어 있고 오늘 아직 실행되지 않았다면 다음 순서를 지킵니다.

1. 설정을 읽고 자동 정리 요청을 대기 상태로 등록합니다.
2. 외부 출처를 요청하고 출처별 결과를 짧은 DB 연결로 저장합니다.
3. 출처 저장이 성공한 뒤 순위 계산을 준비하기 직전에 대기 중 정리를 실행합니다.
4. 정리 결과를 반영한 상태에서 순위·군집 계산을 진행합니다.
5. 이후 주제 방향 자동 생성과 실행 요약을 처리합니다.

수집 과정에서 예외가 발생하면 대기 중 자동 정리를 폐기합니다. 출처별 오류가 예외 대신 결과로 격리되더라도 사용 가능한 출처가 하나도 없으면 `skipped_source_failure`로 기존 순위와 보존 자료를 유지하고 대기 중 정리를 폐기합니다. 일부 출처가 `success`·`partial`·`skipped` 상태로 사용 가능하면 해당 성공 결과를 보존한 채 기존 수집·정리·순위 흐름을 계속합니다.

## 대시보드 진행 표시

대시보드 백그라운드 수집은 자동 정리 **조건 확인**과 실제 **삭제 실행**을 같은 단계처럼 표시하지 않습니다.

- 수집 전에는 정리 대상이 없는지, 또는 정리가 출처 저장 뒤 실행되도록 예약됐는지만 표시합니다.
- 정리가 예약된 경우 진행 이력에 `출처 저장 후 순위 준비 직전에 실행`이라고 명시합니다.
- 출처 저장과 순위 처리가 끝난 뒤 실제 정리가 실행됐다면 삭제 행 수를 함께 표시합니다.
- 모든 사용 가능한 출처가 실패해 `skipped_source_failure`가 되면 예약된 정리가 보류되고 기존 순위·보존 자료가 유지됐다고 표시합니다.

이 진행 표시는 운영 가시성을 위한 설명이며 실제 정리 실행 여부와 데이터 안전 판단은 `post_collection_cleanup_runtime`의 실행 계약을 기준으로 합니다.

## 진입점

- `scripts/refresh_trends.py`: 직접 실행 시에도 `post_collection_cleanup_runtime` 계약을 설치한 뒤 정리·수집 함수를 바인딩합니다.
- `scripts/refresh_trends_safe.py`: 예약/배치 실행 전에 같은 계약을 설치합니다.
- `scripts/refresh_trends_dashboard.py`: 화면 백그라운드 실행 전에 같은 계약을 설치합니다.
- Streamlit 앱은 `src/__init__.py`에서 같은 계약을 설치합니다.

계약 구현은 `src/services/post_collection_cleanup_runtime.py`에 한 곳으로 유지합니다. 각 진입점이 정리 순서를 별도로 다시 구현하지 않습니다.

## 데이터 안전

- `topic_source_links`에 연결된 원본은 기존 보관 규칙대로 보호합니다.
- 자동 정리는 DB 재생성이나 전체 삭제를 수행하지 않습니다.
- 외부 API 요청을 기다리는 동안 장시간 DuckDB 연결을 유지하지 않는 기존 구조를 유지합니다.
- 실제 DB에서 정리 결과를 확인하려면 별도 운영 검증이 필요하며 자동 테스트는 실제 사용자 데이터를 변경하지 않습니다.

## 자동 검증

- `tests/test_post_collection_cleanup_runtime.py`는 수집 성공 시 `수집 → 정리 → 순위 준비` 순서, 예외 실패와 정상 반환 전체 출처 실패에서 정리 취소를 검증합니다.
- `tests/test_short_database_connections.py`는 모든 사용 가능한 출처가 실패하면 기존 순위를 보존하고, 일부 출처가 성공하면 나머지 오류와 무관하게 순위 계산을 계속하는지 검증합니다.
- `tests/test_refresh_cleanup_entrypoint_contract.py`는 직접 실행 진입점도 정리·수집 함수가 같은 후처리 계약에 연결되어 있는지 검증합니다.
- `tests/test_dashboard_cleanup_progress_service.py`는 수집 전 정리 예약 표시, 수집 후 실제 정리 결과, 전체 출처 실패 시 정리 보류·기존 자료 보존 표시와 대시보드 스크립트 연결을 검증합니다.
