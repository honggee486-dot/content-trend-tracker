# 콘텐츠 제작 통합 흐름 검증 0.10.1

## 목적

`AI 요청서 → AI 결과 가져오기 → 글 편집·사실 확인 → 발행 보조`의 수동 제작 흐름이 중간에 끊기거나 같은 작업을 중복 저장하지 않는지 확인했다.

## 대표 검증 시나리오

다음 다섯 유형을 작은 익명화 fixture로 검증했다.

1. 정답 조회형: 일일 퀴즈 정답 정리
2. 문제 해결형: 운영체제 업데이트 후 연결 문제 해결
3. 비교·선택형: 두 스마트폰 카메라 비교
4. 일정·업데이트형: 신제품 출시 일정과 변경 사항
5. 후기·반응형: 무선 이어폰 실사용 후기

각 시나리오는 다음 단계를 통과한다.

```text
빠른 글감 입력 및 자료팩 저장
→ AI JSON 형식 검사
→ generation과 draft 저장
→ 사용자 수정 버전 생성
→ 발행 완료 기록
```

## 확인한 문제와 수정

- 앱을 다시 시작하면 세션의 최근 자료팩이 사라져 요청 양식을 다시 보기 어려움
  - DB에 저장된 최근 자료팩을 선택해 다시 열 수 있도록 보완
- 요청서에서 선택한 자료팩과 초안이 다음 화면에 자동으로 이어지지 않음
  - `content_pack_id`, `draft_id`를 다음 단계 기본 선택으로 전달
- JSON 검사 후 본문이나 AI 제공자를 바꿔도 이전 검사 상태가 화면에 남을 수 있음
  - 자료팩·AI 제공자·원문 응답의 SHA-256 검증 지문이 일치할 때만 저장 허용
- 저장 버튼 재클릭으로 같은 generation·draft 또는 발행 기록이 중복될 수 있음
  - 같은 입력은 기존 저장 ID를 반환하는 멱등 처리 적용
- 제작 단계가 사이드바에만 나뉘어 현재 순서를 놓치기 쉬움
  - 네 단계 공통 진행 표시와 바로 이동 버튼 추가

## 자동 검증 결과

- 새 통합·중복 방지 관련 집중 테스트: 18개 통과
- 비랭킹 테스트 묶음: 81개 통과
- 트렌드 테스트: 40개 통과
- 대규모 합성 랭킹 성능 테스트: 단독 실행 1개 통과
- 확인된 전체 테스트: 122개
- Python 문법 검사: 통과
- Streamlit 헤드리스 시작: 정상
- Streamlit AppTest 주요 네 화면 진입: 예외 0건

Linux Python 3.13 샌드박스에서는 전체 122개를 한 프로세스로 실행할 때 대규모 합성 랭킹 테스트 진입 후 제한 시간에 걸렸다. 같은 테스트는 단독 실행으로 통과했으며 이번 변경은 수집·군집·랭킹 코드를 수정하지 않았다. Windows 사용자 환경에서는 전체 명령으로 다시 확인한다.

## 남은 수동 검증

이번 ZIP에는 실제 누적 DuckDB와 외부 AI 응답이 포함되지 않는다. 따라서 아래는 사용자 환경에서 확인해야 한다.

- 실제 상위 글감 5개로 ChatGPT 또는 Gemini의 JSON 응답 품질 확인
- 검사 후 JSON을 일부 수정했을 때 재검사 안내가 표시되는지 확인
- 같은 응답의 저장 버튼을 반복 눌러 초안이 늘어나지 않는지 확인
- 사실 확인 완료 전 발행 경고가 이해하기 쉬운지 확인
- 네이버 블로그와 티스토리 실제 편집기에 복사했을 때 Markdown 정리량 확인
