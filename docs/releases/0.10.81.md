# 0.10.81

## Gemini 예약 응답 누락 원인 기록

- 예약 글감 분석 응답에 요청한 `cluster_id` 일부가 통째로 빠지면 `response_partial`로 기록합니다.
- 유효하게 반환된 글감은 기존처럼 저장합니다.
- 누락된 글감은 삭제하지 않고 다음 실행 대상으로 유지합니다.
- Gemini API 호출 이력과 수집 경고에 누락 개수와 최대 5개 ID 예시를 남깁니다.
- 출처 수집 성공 판정과 Gemini 후처리 상태는 기존처럼 분리해서 표시합니다.

## 군집 사례 후보 탐색 보강

- 기존 최근 군집 최대 300개 후보를 그대로 사용합니다.
- 사례 제목의 핵심어가 포함된 같은 기간 군집을 최대 700개 추가 조회합니다.
- 최근 생성 시각에 밀려 숨었던 유사 후보를 진단 화면에서 찾을 수 있습니다.
- 이 조회는 `사례 분석 실행`을 눌렀을 때만 수행합니다.
- 군집 연결·점수·순위·유사도 기준은 변경하지 않습니다.

## 분석 입력 상한 영향 분리

- `현재 군집 밖 원문`을 다음 두 값으로 나눠 표시합니다.
  - 출처 그룹별 분석 입력 상한 초과 추정
  - 상한 초과 추정치를 제외한 나머지 미연결
- NAVER 뉴스·블로그와 Daum 웹문서·카페는 각각 하나의 분석 상한을 공유하는 현재 구조를 반영합니다.
- 7일 진단에서도 상한 추정은 현재 순위 계산 기간을 넘겨 과대 계산하지 않습니다.
- 추정치는 실제 품질 필터 순서를 재현한 정확한 실패 건수가 아니며 설정을 자동 변경하지 않습니다.

## 실제 DB 분석 근거

0.10.80 실제 DB 읽기 전용 분석에서 다음을 확인했습니다.

- 최근 예약 실행 30회 요청 1,163개 중 저장 612개
- JSON 절단·구문 오류 6회
- 360초 제한 초과 2회
- 성공 응답에서 요청 ID 일부 누락 2회, 총 18개
- DB 저장 실패는 확인되지 않음
- 최근 72시간 군집 밖 원문 6,835개는 NAVER·Daum 분석 입력 상한 초과량과 일치
- 최신 후보 300개 밖에서 현재 유사도 72% 이상인 분리 후보 다수 확인

600초 적용 후 완료 실행 표본은 분석 당시 없었으므로 시간 연장 효과는 최소 3회 완료 실행 후 다시 판단합니다.

## 이번 버전에서 변경하지 않은 항목

- Gemini 요청당 30개
- 600초 제한 시간
- Gemini 스키마와 사고 수준
- 429 재시도 정책
- NAVER·Daum 분석 입력 상한
- 군집 유사도 기준 0.72
- 자동 군집 병합과 순위 재계산 규칙
- 기존 DuckDB 데이터와 과거 실행 기록
