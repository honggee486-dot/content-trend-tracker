# 0.10.82 제작 화면 이동 상태 안전화

## 변경 목적

작업 대기열, 자료팩 재사용, AI 생성 기록에서 다른 주제·자료팩·초안으로 이동할 때 이전 화면의 `prefill_*` 포인터나 AI 결과 파싱 상태가 함께 남을 수 있는 위험을 줄였습니다.

## 주요 변경

- `src/services/workflow_navigation_service.py`를 추가했습니다.
- AI 요청서 화면은 `prefill_topic_id`와 `prefill_angle`만 유지합니다.
- 새 방향을 지정하지 않은 채 다른 주제로 이동하면 이전 주제의 `prefill_angle`을 제거합니다.
- AI 결과 가져오기 화면은 `prefill_content_pack_id`만 유지합니다.
- 글 편집·발행 보조 화면은 `prefill_draft_id`만 유지합니다.
- 다른 자료팩으로 이동하거나 AI 결과 화면을 떠날 때 다음 파생 상태를 정리합니다.
  - `parse_result`
  - `parse_raw`
  - `parse_pack_id`
  - `parse_provider`
  - `parse_fingerprint`
  - `last_saved_fingerprint`
  - `last_saved_draft_id`
- 자료팩 재사용 payload는 같은 주제로 이동할 때만 유지합니다.
- 작업 대기열, 자료팩 입력값 재사용, AI 생성 기록의 원문 다시 열기·초안 이동에 공통 정리 규칙을 적용했습니다.

## 보존 규칙

다음 값은 자동으로 삭제하지 않습니다.

- `ai_import_raw_<content_pack_id>`에 저장된 사용자의 AI 원문 입력
- 주제별 근거 선택 상태
- 자료팩, 생성 세션, 초안, 리비전, 사실 확인과 발행 기록
- 실제 DuckDB 데이터

이번 변경은 Streamlit `session_state`의 충돌 포인터와 파생 검사 결과만 정리합니다. DB 스키마 변경이나 마이그레이션은 없습니다.

## 검증 범위

- AI 요청서 이동 시 이전 자료팩·초안 포인터 제거
- 다른 주제로 이동할 때 이전 수동·자동 방향 제거
- 다른 자료팩 이동 시 이전 파싱 결과 제거
- 같은 자료팩 재진입 시 현재 파싱 결과 유지
- 기준 자료팩을 알 수 없는 파싱 상태 안전 초기화
- 글 편집 이동 시 요청서·AI 결과 파생 상태 제거
- 자료팩 재사용 payload의 같은 주제 보존
- 사용자 AI 원문 입력 보존
- 빈 화면명 요청 시 상태 불변과 오류 처리
- 고위험 UI 이동부의 공통 정리 서비스 사용

## 변경하지 않은 항목

- DB 테이블·컬럼·상태값
- 자료팩·생성 세션·초안 저장 규칙
- AI JSON 파서와 검증 규칙
- Gemini 요청량·제한 시간·재시도 정책
- 수집·군집·순위 계산
