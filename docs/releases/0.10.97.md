# 0.10.97 Gemini 모델·기능별 사용 로그

## 변경

- 설정 → AI·품질에 `Gemini API 모델·기능별 사용 로그`를 추가했습니다.
- 3.6 Flash 자동·예약 글감 분석과 3.5 Flash-Lite 자료 정리·군집 검토를 모델·기능별로 분리합니다.
- 최근 30일 호출·성공·실패·재시도·요청 항목과 입력·출력·사고·전체 토큰을 표시합니다.
- 최근 호출 상세에서 시각, 모델, 기능 ID, 상태, 토큰, HTTP 상태와 오류 유형을 확인할 수 있습니다.

## 범위와 안전

- 캐시 적중은 실제 외부 API 호출 수에서 제외합니다.
- API 키가 없어 군집 검토를 건너뛴 경우에는 호출 기록이 생기지 않습니다.
- 과거 DB에 선택적 토큰 컬럼이 없어도 읽기 전용 호환 표시합니다.
- 이 화면은 로컬 프로그램 기록이며 Google AI Studio의 공식 남은 RPM·RPD·결제 사용량은 아닙니다.
- DB 스키마와 기존 수집·자료팩·초안·리비전·사실 확인·발행 기록을 변경하지 않습니다.
