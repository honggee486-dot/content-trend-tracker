# 0.10.72 DuckDB 백업·안전 복구·무결성 검사

- 설정 화면에 현재 DuckDB 무결성 검사, 수동 백업, 백업 검사와 명시적 확인 복구 기능을 추가합니다.
- 백업은 수집 잠금을 획득한 뒤 `CHECKPOINT`를 실행하고 DB 연결을 닫아 임시 복사본을 만듭니다.
- 임시 복사본을 읽기 전용으로 다시 열어 필수 테이블과 사용자 작업 테이블 행 수를 확인한 뒤에만 최종 백업으로 확정합니다.
- 사용자 작업 연결이 끊긴 행은 주의로 표시하고, 필수 테이블 누락·DB 열기 실패·0바이트 파일은 백업·복구 차단 오류로 처리합니다.
- 복구 전에는 현재 DB를 `pre_restore` 백업으로 자동 보존하고, 복구 후 현재 스키마의 추가형 호환 마이그레이션과 무결성 검사를 실행합니다.
- 복구 후 오류가 발생하면 `pre_restore` 백업으로 자동 원상 복구를 시도합니다.
- 복구는 체크박스와 `복구` 확인 문구를 모두 요구하며 프로젝트 `backups` 폴더에서 프로그램이 만든 DuckDB만 허용합니다.
- 수동 백업은 최근 10개, 복구 전 자동 백업은 최근 5개를 보관합니다.
- 활성 수집 잠금, DB 파일 점유, 비어 있지 않은 WAL 또는 디스크 여유 공간 부족이 있으면 기존 DB를 변경하지 않고 중단합니다.
- `backups` 폴더는 Git과 안전 업로드 ZIP에서 제외하며 `.env`, API 키, Parquet, 로그와 브라우저 정보는 백업하지 않습니다.
- DB 스키마와 기존 데이터 정리·수집·점수·Gemini·초안·발행 흐름은 변경하지 않습니다.
- 실제 Windows 파일 잠금, WAL과 강제 종료 시나리오는 적용 후 로컬 Agent 검증 대상으로 남깁니다.
