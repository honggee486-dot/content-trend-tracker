# 0.10.87 주제 방향 v6 품질·운영 진단

## 변경 목적

0.10.86에서 추가한 검색 의도·독자 질문·수요 근거·점수 계약이 실제 운영 데이터에서도 올바르게 저장되는지 설정 화면에서 직접 확인할 수 있도록 읽기 전용 진단을 추가했습니다. 표본이 부족한 단계와 실제 저장 이상을 구분하며 외부 API나 운영 설정을 자동 변경하지 않습니다.

## 주요 변경

- 설정 화면에 `주제 방향 v6 품질·운영 진단`을 기본 접힘 상태로 추가합니다.
- `gemini_api_calls`에 선택적 `feature_version`을 추가해 앞으로의 주제 방향 v6 호출을 이전 계약과 정확히 구분합니다.
- v6 방향에 대해 다음 항목을 확인합니다.
  - 저장된 글감·방향 수와 글감당 3방향 완성 여부
  - 검색 의도·독자 질문·검색어·수요 근거·점수 이유의 필수값
  - 다섯 하위 점수의 허용 범위와 Python 총점 일치 여부
  - `angle_order`가 총점 내림차순인지 여부
  - 저장된 원문 근거 ID가 현재 `source_items`에 존재하는지 여부
  - 1순위 방향의 계약 완전성
  - 공백 없는 8자 이하 단일어 검색어 비율
- v6 호출 기록에 대해 성공 요청 수, 요청 글감 누계, 현재 15개·사고 수준·제한 시간 일치 여부, 검증 실패, 재시도, 생성 토큰과 소요 시간을 표시합니다.
- 현재 요청 상한·사고 수준·제한 시간과 모두 일치한 성공 요청 4회·요청 글감 60개만 v6 운영 판단의 최소 표본으로 사용합니다.
- 현재 기회 점수 기준에서 분석 완료·대기 글감 수와 요청당 처리량 기준 대기 해소 예상 횟수를 표시합니다.
- 최근 점검 사례에는 제목·순위·점수와 확인 항목만 표시하며 URL·API 키·내부 원문 내용은 노출하지 않습니다.

## DB 호환성

기존 `gemini_api_calls`에 다음 컬럼을 추가형으로 더합니다.

- `feature_version VARCHAR DEFAULT ''`

기존 호출 이력은 빈 버전으로 유지합니다. Gemini 직접 초안 호출은 기존 기능 버전 `4`, 새 주제 방향 호출은 기능 버전 `6`을 기록합니다. 기존 호출·방향·자료팩·초안·사실 확인·발행 기록은 삭제하거나 다시 생성하지 않습니다.

## 유지한 동작

- 주제 방향 Gemini 호출은 요청당 15개, 동시 요청 1개, Google 검색 비활성 상태를 유지합니다.
- 사용자가 설정한 `.env`와 Windows 작업 스케줄러를 자동 변경하지 않습니다.
- 진단은 읽기 전용이며 외부 API를 호출하지 않습니다.
- 표본이 부족하면 처리량·사고 수준·프롬프트·군집 기준을 그대로 유지합니다.
- 문제가 있어도 한 버전에서 여러 기준을 동시에 변경하지 않습니다.

## 검증

- 신규 서비스 테스트에서 정상 v6 계약·근거 연결·운영 조건·대기 글감 계산을 검증합니다.
- 점수 불일치·정렬 이상·끊어진 원문 연결·짧은 단일어 검색어 사례를 검증합니다.
- 전체 pytest, Python 구문 검사와 `git diff --check`를 실행합니다.
- 실제 `.env`, DuckDB와 Windows 작업 스케줄러는 검증 과정에서 변경하지 않습니다.
