# 0.10.75 초안 리비전 비교·안전 복원

- 글 편집 화면 아래에 기본 접힘 상태의 `초안 버전 기록·비교·복원` 영역을 추가합니다.
- 저장된 리비전 번호, 저장 시각과 수정 메모를 확인할 수 있습니다.
- 선택한 과거 리비전과 현재 편집본의 제목·요약·카테고리·태그·Markdown 본문 차이를 비교합니다.
- 본문은 줄 단위 diff와 추가·삭제 줄 수를 표시하며 긴 차이는 화면에서 일부만 보여줍니다.
- 복원은 체크박스와 `복원` 확인 문구를 모두 요구합니다.
- 현재 편집본이 현재 리비전과 다르면 복원 전에 `복원 전 현재 편집본 자동 보존` 리비전을 먼저 만듭니다.
- 선택한 과거 내용은 기존 행을 덮어쓰지 않고 새 리비전 번호로 저장한 뒤 현재 초안에 반영합니다.
- 기존 리비전, 출처, 이미지 지시와 사실 확인 기록은 삭제하지 않습니다.
- 복원 후 주제 상태를 `editing`으로 바꾸고 기존 사실 확인 상태를 다시 검토하도록 안내합니다.
- 기존 DB 스키마와 데이터 흐름은 변경하지 않으며 `draft_revisions` 테이블을 그대로 사용합니다.
