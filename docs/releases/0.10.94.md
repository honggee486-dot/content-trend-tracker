# 0.10.94 설정 진단·백업 탭 정리

## 변경

- 설정 화면 위에 먼저 표시되던 Gemini 안정성, 수집 출처 다양성, 군집 사례 진단을 `AI·품질 → 품질·운영 진단` 탭 안으로 옮겼습니다.
- 데이터베이스 백업·안전 복구 화면을 `데이터·연동 → 백업·복구` 탭 안으로 옮겼습니다.
- 설정 화면의 상위 메뉴와 보조 탭을 가운데 정렬하고 각 버튼 최소 폭을 12.5rem으로 넓혀 긴 문구가 잘리지 않게 했습니다.
- 좁은 화면에서는 버튼을 줄바꿈하지 않고 가로 스크롤로 확인할 수 있습니다.
- 선택하지 않은 설정 영역은 기존처럼 렌더링하지 않아 긴 스크롤과 불필요한 DB 조회를 줄입니다.

## 안전 경계

- 기존 진단 계산, 백업 생성·검사·복구 절차와 확인 문구는 변경하지 않습니다.
- DB 스키마와 기존 설정·자료팩·초안·리비전·사실 확인·발행 기록은 변경하거나 삭제하지 않습니다.
- 외부 API 호출, 자동 로그인, 쿠키 저장과 자동 게시를 추가하지 않습니다.
