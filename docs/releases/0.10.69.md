# 0.10.69 사실 확인 준비도 진단

- 설정의 진단 영역에 초안별 사실 확인 준비도 화면을 추가합니다.
- 초안을 수정 필요, 확인 대기, 시점 의존 재확인, 확인 항목 없음, 발행 준비, 발행 완료, 발행 후 확인 필요로 구분합니다.
- 미확인·수정 필요·확인 완료·재확인 항목 수, 확인 완료지만 근거 URL이 없는 항목, 마지막 수정·발행 시각과 다음 행동을 표시합니다.
- 환율·주가·가격·날씨·스포츠 결과 같은 빠른 정보는 24시간, 현재 직책·정책·마감 같은 비교적 느린 정보는 7일을 재확인 참고 기준으로 사용합니다.
- 사실 확인 항목이 없는데 시점 의존 표현이 있는 초안과 미확인 항목이 7일 이상 남은 초안을 별도 주의 대상으로 표시합니다.
- 이미 발행했지만 미확인·수정 필요·재확인 항목이 남은 글도 발행 후 확인 필요로 표시합니다.
- 키워드 기반 재확인 판정은 보조 신호이며 실제 공식 자료의 적용 시점과 변경 주기를 우선하도록 안내합니다.
- 이번 버전은 기존 초안·사실 확인·발행 기록을 읽기만 하며 본문, 상태, 근거 URL, 주제와 발행 기록을 자동 변경하지 않습니다.
- DB 스키마, 외부 API 호출량, Gemini 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
