# 0.10.91 티스토리 발행 보조 흐름 단순화

## 변경 내용

- 티스토리 프로필에서 로그인 주소와 글쓰기 주소를 각각 관리하지 않고 `내 티스토리 블로그 주소` 하나만 입력하도록 단순화했습니다.
- 개인 블로그 주소에서 실제 새 글 편집기 `/manage/newpost` 주소를 자동 생성합니다.
- 로그인되어 있으면 `티스토리 글쓰기 바로 열기`가 새 글 편집기로 바로 이동하며, 로그인 보조 버튼은 문제 해결 도움말 안으로 옮겼습니다.
- 발행 보조를 `준비 저장 → 전달 데이터 복사 → 글쓰기 화면 열기 → 확장 진단·입력 → 직접 확인`의 5단계로 재구성했습니다.
- 주소, 출력 형식, 카테고리, 태그, 이미지, 저장 버튼과 글쓰기 버튼에 도움말을 보강했습니다.

## 호환성과 안전

- 기존에 저장된 구체적인 티스토리 글쓰기 주소는 개인 블로그 주소로 정상화해 계속 사용합니다.
- `https://www.tistory.com/` 같은 일반 포털 주소는 실제 글쓰기 주소로 간주하지 않고 설정 필요 상태로 안내합니다.
- DuckDB 스키마, 초안, 발행 준비, 발행 기록과 Chrome 확장 권한은 변경하지 않습니다.
- 자동 로그인, 쿠키 저장, CAPTCHA 우회, 게시·임시저장 버튼 자동 클릭을 추가하지 않습니다.
