# 0.10.70 콘텐츠 작업 대기열

- 오늘의 트렌드 첫 화면에 저장된 콘텐츠 작업의 다음 행동을 보여주는 읽기 전용 대기열을 추가합니다.
- 같은 주제를 여러 단계에 중복 표시하지 않고 자료 보완, AI 요청서 준비, AI 결과 대기, 초안 편집, 사실 확인, 발행 준비 중 현재 가장 앞선 단계 하나만 표시합니다.
- 각 작업에는 막힌 이유, 마지막 활동 시각과 다음에 이동할 화면·행동 하나를 표시하며 주제·자료팩·초안을 선택한 상태로 해당 화면을 엽니다.
- 최신 자료팩으로 만든 초안이 아직 없으면 기존 초안보다 AI 결과 대기를 우선하고, 발행 완료와 보류 작업은 기본 대기열에서 제외합니다.
- 마지막 제작 활동 후 7일 이상 지난 작업은 별도 중복 행을 만들지 않고 현재 단계 안에서 방치 주의로 먼저 표시합니다.
- 수집·순위 재계산·Gemini 방향 생성이 진행 중일 때는 대기열 DB 조회를 건너뛰어 진행 화면을 방해하지 않습니다.
- 대기열 조회나 표시가 실패해도 오늘의 트렌드 화면은 계속 열리며 수집·순위 계산 흐름에는 영향을 주지 않습니다.
- 이번 버전은 기존 주제·자료팩·생성 세션·초안·사실 확인·발행 기록을 읽기만 하며 상태, 점수, 본문과 기록을 자동 변경하지 않습니다.
- DB 스키마, 외부 API 호출량, Gemini 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
