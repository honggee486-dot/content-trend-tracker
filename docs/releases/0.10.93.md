# 0.10.93 발행 채널 연결 준비도 진단

## 변경

- 설정의 발행 채널 화면에 Blogger 3개·네이버 1개·티스토리 1개의 연결 준비도를 표시합니다.
- 전체 연결 수와 플랫폼별 연결 수를 함께 보여주고, 미설정과 주소 형식 오류를 구분합니다.
- 각 프로필 편집 영역과 발행 보조 3단계에서도 현재 연결 상태와 필요한 설정 경로를 안내합니다.
- 준비되지 않은 프로필은 글쓰기 버튼을 노출하기 전에 연결 정보 저장을 먼저 안내합니다.

## 진단 범위

- 진단은 저장된 주소 형식만 읽기 전용으로 확인합니다.
- 외부 접속, 로그인, 쿠키 확인과 실제 편집기 이동은 수행하지 않습니다.
- 연결 준비 완료는 실제 브라우저 이동 성공을 보증하지 않으며 다음 실사용 검증에서 확인합니다.

## 안전 경계

- DB 스키마와 기존 프로필·초안·발행 기록을 변경하거나 삭제하지 않습니다.
- 자동 로그인, 쿠키 저장, CAPTCHA 우회와 게시 버튼 자동 클릭을 추가하지 않습니다.
