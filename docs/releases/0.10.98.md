# 0.10.98 설정 진단 DuckDB 연결 재사용

## 확인된 문제

설정 → AI·품질 → 품질·운영 진단을 열 때 Streamlit 앱의 쓰기 가능 DuckDB 연결이 이미 열린 상태에서 진단 코드가 같은 파일을 `read_only=True`로 다시 열었습니다. DuckDB는 같은 프로세스에서 같은 파일을 서로 다른 구성으로 여는 것을 거부해 Gemini 진단·사용 로그와 수집 출처 다양성 진단이 모두 표시되지 않았습니다.

## 변경

- 설정 화면이 보유한 기존 DuckDB 연결을 품질 진단 함수에 전달합니다.
- Gemini 안정성, 모델·기능별 사용 로그와 출처 다양성 진단은 전달받은 연결에서 SELECT 쿼리만 실행합니다.
- 전달받은 연결은 진단 코드가 닫지 않으며 앱이 기존 수명 주기에 따라 관리합니다.
- 앱 연결이 없는 독립 호출은 기존 읽기 전용 연결 폴백을 유지합니다.

## 안전 범위

- DB 스키마와 마이그레이션을 변경하지 않습니다.
- 수집 원본, 순위, 자료팩, 초안, 리비전, 사실 확인과 발행 기록을 변경하지 않습니다.
- Gemini API 호출 수, 모델 선택과 군집 검토 정책을 변경하지 않습니다.
