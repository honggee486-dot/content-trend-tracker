# 0.10.58 Gemini 글감 40개 제한·저장 진단

- 자동·예약 Gemini 글감 분석의 요청당 기본값과 허용 상한을 40개로 낮춥니다.
- 실제 `.env`에 더 큰 값이 있어도 프로그램이 40개로 제한합니다.
- 설정 화면에 최근 요청 대비 저장 글감, 미처리 글감, 최근 10회 저장률과 부분·실패 횟수를 표시합니다.
- 진단은 기존 `collection_runs`와 `collection_run_sources`만 읽으며 DB 마이그레이션이나 추가 API 호출을 만들지 않습니다.
- 저장되지 않은 글감은 기존 규칙대로 다음 실행 대상에 남습니다.
- 글감 목록의 방향 API 저장 완료·미저장 행 색상 구분은 유지합니다.
