# 0.10.95 동일 고유 회차 군집 병합 보강

## 변경

- `제1235회`와 `1235회`처럼 같은 회차 표기를 하나의 식별 토큰으로 정규화합니다.
- 3자리 이상 `회·차` 식별자는 반복 빈도와 관계없이 군집 비교 후보에 우선 포함합니다.
- 같은 긴 회차와 `로또·로또복권`처럼 겹치는 대상 표현이 있으면 부가 제목이 달라도 같은 사건 후보로 비교합니다.
- `1235회`와 `1236회`, 같은 숫자를 가진 서로 다른 대상은 계속 분리합니다.
- 순위 알고리즘 버전을 갱신해 적용 후 기존 저장 순위를 새 규칙으로 다시 계산합니다.

## 안전 경계

- 기존 원본 `source_items`, 주제, 자료팩, 초안과 발행 기록을 수정하거나 삭제하지 않습니다.
- DB 스키마와 수집 API 호출 방식은 변경하지 않습니다.
- 실제 로컬 DB의 로또 사례는 적용 후 순위 재계산 결과로 최종 확인합니다.
