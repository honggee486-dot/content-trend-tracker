# 0.10.110 AI 요청·블로그 제작 흐름 안정화

릴리스 날짜: 2026-08-15

## 핵심 변경

- 실제 블로그 운영 흐름에 맞춰 글감 추천·프로필 표시를 정리하고 저장된 블로그 프로필 이름을 추천 표시 이름의 기본값으로 사용합니다.
- Gemini 글감 분석의 요청량과 제한 상태를 보수적으로 다루고, 부분 응답에서도 이미 유효한 결과를 보존하면서 누락·검증 탈락 항목만 필요한 범위에서 보강합니다.
- AI 요청서는 답변 시점의 최신 웹 검색과 초안 후 세 차례 추가 웹 재검증을 요구하고, 각 단계에서 사실 정확성을 유지한 자연스러운 인간 편집 품질을 다시 점검합니다.
- `schema_version 2.1`에 검색 의도·키워드·메타 설명을 포함한 SEO와 검증 가능한 무료 이미지 정보를 추가하고, 이미지 위치와 생성용 프롬프트를 구조화합니다.
- ChatGPT UI 내부 `contentReference`·`oaicite` 같은 참조 문자열은 최종 JSON에 포함하지 않도록 요청하고 파서에서도 제거합니다.
- 가격·정책·통계·공식 기능처럼 공식 화면 자체가 근거가 되는 경우 공개 공식 페이지의 정확한 캡처 대상과 운영자 작업 지시를 제공합니다. 로그인·계정·결제·쿠키 등 개인정보 화면은 캡처 대상으로 요구하지 않습니다.
- 테스트 실행 비용과 반복 검증 시간을 줄이도록 pytest 병렬 실행과 `work/*` 업데이트 증분 검증 라우팅을 보강하면서 릴리스 후보의 전체 회귀 검증은 유지합니다.
- 적용 도구는 보호 파일, 최신 기본 브랜치 관계, `behind 0`·`ahead 1`, 직접 부모와 단일 `release:` 커밋 조건을 검증하고 비강제 fast-forward만 허용합니다.

## 호환성과 안전 경계

- 기존 DuckDB 데이터·설정·원본·자료팩·AI 기록·초안·리비전·사실 확인·발행 기록을 보존합니다.
- 기존 추가형 호환 마이그레이션 원칙을 유지하며 테이블·컬럼·상태 의미를 파괴적으로 삭제하거나 바꾸지 않습니다.
- 한 출처나 Gemini 후처리 실패가 다른 정상 수집 결과를 취소하지 않는 부분 성공 원칙과 수동 최종 발행 원칙을 유지합니다.
- `.env`, 실제 DB/WAL/잠금, Parquet, 로그, OAuth·쿠키·브라우저 인증 상태, 가상환경·캐시·테스트/빌드 산출물은 릴리스 대상에서 제외합니다.
- 자동 로그인·쿠키 저장·CAPTCHA 우회·무인 자동 공개 발행은 추가하지 않습니다.

## 릴리스 검증 게이트

최종 릴리스 후보는 최신 `origin/main`의 직접 자식인 단일 커밋이어야 하며 `behind 0`, `ahead 1`을 만족해야 합니다. 후보 SHA 자체에서 다음 검증을 모두 통과한 경우에만 `main`에 비강제 fast-forward로 반영합니다.

- Windows / Python 3.14.6 개발 하네스 smoke
- Python `compileall`
- 저장소 text hygiene
- Public tracked-tree safety
- 전체 pytest
- 격리 Chromium Browser Regression

실제 DB 초기화·수정, 외부 유료 API, Windows 작업 스케줄러 쓰기, 실제 로그인 브라우저와 공개 발행은 자동 릴리스 검증에 포함하지 않습니다.

## 적용 후 확인

`docs/NEXT_WORK_0.10.110.md`에 따라 Blogger부터 실제 정보성 글 한 편의 `글감 선택 → 자료팩 → AI 요청서 → AI 결과 검사 → 편집·사실 확인 → 발행 보조` 흐름을 확인합니다. 자동 검증이 완료한 코드·브라우저 회귀를 다시 반복하는 대신, 실제 사용자 데이터·실계정·최종 공개 화면에서만 확인할 수 있는 항목을 중심으로 점검합니다.
