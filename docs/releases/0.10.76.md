# 0.10.76

- 글 편집 화면 아래에 기본 접힌 `사실 확인 변경 이력·안전 되돌리기` 패널을 추가했습니다.
- 기능을 처음 연 시점의 사실 확인 상태·확인 메모·근거 URL을 기준점으로 자동 보존합니다.
- 기준점 이후 변경을 감지해 변경 전후 값, 시각과 사유를 `fact_check_history`에 저장합니다.
- 같은 현재 상태를 반복 조회할 때 중복 이력이 생성되지 않도록 했습니다.
- 선택한 변경의 직전 상태로 되돌릴 수 있으며, 되돌리기 자체도 새 이력으로 남깁니다.
- 되돌린 뒤 발행 전 주제의 `editing`·`publish_ready` 상태를 다시 계산합니다.
- 이미 발행된 주제는 사실 확인 되돌리기로 `published` 상태를 임의 해제하지 않습니다.
- 기존 사실 확인 항목과 과거 이력을 물리 삭제하지 않습니다.
- 초안 본문은 자동 변경하지 않으며, 되돌린 뒤 주장·본문·근거 재검토를 안내합니다.
