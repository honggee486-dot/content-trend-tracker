# 0.10.64 검색어 성과 진단

- 설정의 수집 이력 화면에 최근 7일·30일 기준 검색어 성과 진단을 추가합니다.
- NAVER·Daum 전체 또는 포털별로 실제 원문을 발견한 검색어 수, 발견 기록, 신규 원문, 고유 원문, 재발견과 중복 발견률을 확인할 수 있습니다.
- 검색어·세부 출처별 신규율, 평균·최고 검색 결과 순위와 마지막 유효 발견 시각을 상세 표로 제공합니다.
- 기존 `collection_query_discoveries` 원장을 읽기 전용으로 집계하며 DB 스키마와 수집·점수 계산은 변경하지 않습니다.
- 현재 원장에 없는 결과 0건 요청, API 오류와 전체 요청 횟수는 추정하지 않으며 화면에서도 전체 검색 성공률로 해석하지 않도록 안내합니다.
- Gemini 글감 25개 제한, 사고 수준, 240분 스케줄러와 기존 수집·자료팩·초안 데이터는 변경하지 않습니다.
