# 0.10.67 출처 신선도·스케줄러 상태 진단

- 설정의 수집 이력 화면에 저장된 자동 수집 주기와 실제 백그라운드 실행 시각을 비교하는 상태 진단을 추가합니다.
- 한 주기 초과는 주의, 두 주기 초과는 지연으로 표시하며 현재 240분 설정에서는 8시간이 지연 기준입니다.
- YouTube·NAVER·Daum·Google Trends·Wikimedia 등 출처별 마지막 시도, 마지막 정상 수집, 마지막 신규 원문, 연속 문제와 최근 오류를 확인할 수 있습니다.
- 최신 출처 결과가 부분 성공·실패이면 시간과 무관하게 경고하고, 신규 원문이 없다는 이유만으로 장애 처리하지 않습니다.
- 출처 신선도는 수동 수집과 예약·백그라운드 수집 이력을 함께 사용하며, 스케줄러 상태는 실제 `background_refresh` 기록으로 판단합니다.
- Windows 작업 스케줄러 자체를 직접 조회하거나 변경하지 않으며 기존 수집 호출량·점수·군집·원문·초안 데이터도 변경하지 않습니다.
- Gemini 글감 25개 제한과 저장된 240분 스케줄러 설정은 유지합니다.
