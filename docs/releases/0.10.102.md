# 0.10.102 Flash-Lite 기본 주제 군집화

## 변경

- `gemini-3.5-flash-lite`를 군집 보조 검토가 아닌 기본 제목 분류 엔진으로 전환했습니다.
- 같은 URL만 원자 후보로 먼저 정리하고 Flash-Lite가 같은 사건별 묶음·분리와 대표 제목을 직접 반환합니다.
- 프로그램은 AI 요청 후보 준비와 날짜·회차·제품·금액·주가 방향 충돌 차단만 수행합니다.
- 정상 AI 경로에서는 유사도 0.72 최종 군집, 조각 재병합, 대표 제목 점수 보정을 실행하지 않습니다.
- 0.10.101 반복 모델명 감점과 과거 군집 쌍 재검토 후처리를 제거했습니다.

## 부분 성공과 폴백

- AI 응답에서 누락되거나 검증을 통과하지 못한 후보는 개별 군집으로 유지합니다.
- 일부 배치 성공은 다른 배치 실패 때문에 취소하지 않습니다.
- API 키가 없거나 모든 AI 군집 요청이 실패한 경우에만 기존 유사도 군집을 비상 폴백으로 사용합니다.
- 새 호출 기능 ID는 `trend_cluster_grouping_v2`이며 사용 로그에서 모델·후보 수·토큰을 확인할 수 있습니다.

## 안전 경계

- Google 검색, 초안 생성, 자동 로그인과 자동 게시를 사용하지 않습니다.
- DB 스키마, 원본 자료, 자료팩, 초안, 사실 확인과 발행 기록을 변경하지 않습니다.
