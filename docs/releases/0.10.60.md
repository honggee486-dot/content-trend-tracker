# 0.10.60 Gemini 글감 30개 제한·생성 토큰 경고

- 자동·예약 Gemini 글감 분석의 요청당 기본값과 허용 상한을 40개에서 30개로 낮춥니다.
- 실제 `.env`에 40개 이상이 남아 있어도 프로그램이 요청당 최대 30개로 제한합니다.
- 오늘 사용량 카드에 `출력 토큰 + 사고 토큰`의 1회 최대 생성 토큰을 표시합니다.
- 최근 Gemini 호출 상세에 생성 토큰 합계, 출력 한도 대비 사용률과 검증 오류 요약을 추가합니다.
- 생성 토큰이 65,000 이상이면 한도 근접 경고를 표시해 JSON 잘림이나 필수 항목 누락 가능성을 확인할 수 있게 합니다.
- DB 스키마와 외부 API 호출 방식은 변경하지 않으며, 저장되지 않은 글감은 다음 실행 대상으로 유지합니다.
