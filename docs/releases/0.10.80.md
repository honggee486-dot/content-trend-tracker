# 0.10.80

## 군집 실패·단일 출처 사례 상세 보기

설정 화면의 수집 출처 다양성 진단 아래에 `군집 실패·단일 출처 사례 상세 보기`를 기본 접힘 상태로 추가했습니다.

- 최근 24시간·72시간·7일의 군집 밖 원문 조회
- 단일 출처 군집 조회
- 출처·제목·예상 원인 필터
- 기존 군집화와 같은 제목 정규화·유사도 계산 재사용
- 다른 출처가 포함된 가장 유사한 군집 후보 표시
- 후보 유사도, 공통 핵심어, 시간 차이 표시
- Google Trends 검색어형 단독 사례 확인
- 유사 후보 없음, 공통 핵심어 부족, 72% 기준 미달, 시간 차이, 분석 입력 상한·필터·재계산 시점 가능성 분류

이 기능은 `source_items`, `trend_clusters`, `trend_cluster_items`를 읽기만 하며 군집을 자동 병합하거나 기준을 변경하지 않습니다. 표시 원인은 다음 로컬 Agent 분석 대상을 좁히기 위한 추정입니다.

## Gemini 글감 분석 제한 시간 10분

Gemini 주제 방향·요약 요청 1개의 기본 제한 시간을 360초에서 600초로 늘렸습니다.

- 새 기본값: `GEMINI_TOPIC_ANGLE_TIMEOUT_SECONDS=600`
- 기존 `.env`에 과거 기본값 `360`이 남아 있으면 프로그램이 600초로 자동 보정
- 사용자가 360이 아닌 별도 값을 지정했다면 기존 값 유지
- 허용 범위는 기존과 동일하게 최대 900초

예약 수집은 대상 조회 후 DB 연결을 닫고 API 요청을 수행한 뒤, 검증된 글감만 짧은 트랜잭션으로 저장합니다. 저장되지 않은 글감은 다음 실행 대상에 남습니다. 먼저 10분 제한으로 3~5회 실행을 관찰하고, 계속 부분 저장이나 검증 실패가 발생할 때 응답 원문·검증 오류·프롬프트 구조를 별도로 분석합니다.

## 콘텐츠 작업 대기열 화면 축소

첫 화면을 과도하게 차지하던 `AI 요청서 준비` 항목을 하나의 기본 접힌 묶음으로 변경했습니다.

- 상단 작업 지표는 그대로 표시
- `AI 요청서 준비 N개 보기`를 기본 접힘으로 표시
- 펼친 뒤 각 주제의 이어서 하기 버튼 사용
- 각 항목의 `수집 근거 보기`도 기존처럼 안쪽에서 기본 접힘 유지
- AI 결과 대기·초안 편집·사실 확인·발행 준비 항목은 기존처럼 바로 표시
