# 0.10.65 사용자 글감 평가 진단

- 설정의 수집 이력 화면에 사용자 글감 평가 진단을 추가합니다.
- 좋은 글감·애매한 글감·쓸모없는 글감·잘못 묶인 주제의 현재 평가 수와 비율을 표시합니다.
- 평가를 저장한 당시의 원문 수, 중복을 제외한 독립 근거 수, 출처 유형 수와 발행처 수를 평가 유형별로 비교합니다.
- 현재 군집에 연결된 출처 유형과 검색어별로 좋은 평가·제외 평가 관계를 표시하되, 인과관계나 자동 감점 근거로 해석하지 않도록 안내합니다.
- 최근 평가 상세에서 메모와 평가 당시 근거 품질을 확인할 수 있습니다.
- 이번 진단은 읽기 전용이며 트렌드 점수, 추천 상태, 군집, 검색어와 원문을 자동 변경하지 않습니다.
- DB 스키마, 수집 호출량, Gemini 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
