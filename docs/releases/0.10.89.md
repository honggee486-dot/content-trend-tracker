# 0.10.89 블로그 발행 워크플로 확장

## 변경 목적

0.10.88 이후 구현된 블로그 발행 준비·입력 보조·Blogger 초안·성과 비교 기능을 하나의 공식 버전으로 정리하고, 현재 코드와 운영 문서의 기준을 일치시킵니다.

## 주요 변경

### 4개 전문 발행 채널

- 티스토리 생활·정책·제도
- 티스토리 IT·AI·앱·PC 사용법
- 네이버 생활밀착·계절·국내 관심
- Blogger 해외 서비스·글로벌 기술·장기 가이드

글감의 제목·카테고리·태그·요약·본문을 바탕으로 추천 발행처와 이유를 표시하며, 사용자가 다른 프로필을 선택한 경우 그 배정을 별도 보존합니다. 기존 네이버·티스토리 기본 프로필과 사용자가 설정한 주소는 가능한 범위에서 재사용합니다.

### SEO·이미지 3개 슬롯·복사 패키지

초안과 발행처 조합별로 SEO 제목, 메타 설명, 핵심 키워드와 이미지 3개의 위치·대체텍스트·메모를 저장합니다. 제목·본문·태그·메타 설명을 개별 복사하거나 전체 발행 패키지로 복사할 수 있습니다.

이미지 파일이나 로컬 경로는 저장하지 않으며, 원본 초안과 리비전은 변경하지 않습니다.

### Chrome 편집기 입력 보조

Manifest V3 확장 프로그램은 사용자가 버튼을 누른 현재 탭에서만 제목·본문·태그·검색 설명 입력을 시도합니다. 현재 문서와 접근 가능한 same-origin iframe을 탐색하고, 선택자·iframe 위치·입력 성공 여부만 담은 개인정보 제한 호환성 보고서를 제공합니다.

확장 프로그램은 로그인 정보·쿠키·브라우저 프로필을 저장하지 않으며 임시저장·게시 버튼을 자동으로 누르지 않습니다.

### Blogger 공식 API 비공개 초안

사용자가 데스크톱 OAuth 동의 화면에서 직접 승인한 뒤 Blogger 블로그를 발행 프로필에 연결할 수 있습니다. 전송은 `posts.insert(isDraft=true)`만 사용하며 공개 게시·예약 게시 API는 구현하지 않습니다.

OAuth 클라이언트와 토큰 파일은 로컬 `data` 폴더에만 두고 Git과 안전 ZIP에서 제외합니다. 동일한 초안·프로필·내용은 콘텐츠 해시와 원격 게시물 ID를 재사용해 중복 초안 생성을 방지합니다.

### 발행 성과 기록·비교

발행 후 7일·30일·90일의 조회수, 검색 유입, 좋아요, 댓글과 공유를 수동 스냅샷으로 누적 보존합니다. 같은 글·같은 관찰 구간의 최신 스냅샷만 사용해 발행처별 평균·중앙 조회수, 검색 비중과 반응률을 비교합니다.

프로필당 최소 3개 글과 비교 가능한 발행처 2곳이 쌓이기 전에는 표본 부족으로 표시합니다. 표본이 충족돼도 추천 발행처 규칙을 자동 변경하지 않습니다.

## 데이터와 호환성

추가형 테이블만 사용합니다.

- `blog_profile_strategies`
- `draft_blog_assignments`
- `draft_publish_preparations`
- `blogger_profile_bindings`
- `blogger_draft_uploads`
- `publish_performance_snapshots`

기존 DuckDB 데이터, 초안, 리비전, 사실 확인과 발행 기록을 삭제하거나 의미를 변경하지 않습니다.

## 보안과 운영 경계

- 자동 로그인·쿠키 저장·CAPTCHA 우회 없음
- Chrome 확장 프로그램의 무인 반복 입력·자동 저장·자동 게시 없음
- Blogger 공개 게시·예약 게시 API 없음
- OAuth 클라이언트·토큰의 Git·ZIP 포함 금지
- 성과 지표를 이용한 추천 규칙 자동 변경 없음
- 실제 편집기·OAuth·Blogger 초안·성과 표본은 사용자 로컬 환경에서 별도 검증
