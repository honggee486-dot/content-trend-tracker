# 0.10.63 적용 도구 실시간 검증 출력·UTF-8 보정

- `compileall`과 `pytest`만 현재 콘솔로 실시간 전달해 테스트 진행 점과 퍼센트를 실행 중 확인할 수 있도록 합니다.
- Git 해시·브랜치·상태처럼 내부 판단에 필요한 명령은 기존처럼 출력을 캡처하고, 종료 코드는 계속 직접 확인합니다.
- `git fetch`의 진행 문자를 조용히 처리해 Windows 콘솔에서 2/8·3/8 단계 제목이 중복해서 다시 그려지는 현상을 줄입니다.
- Windows PowerShell 5.1의 콘솔과 Python 입출력을 UTF-8로 맞춰 pytest 실패 내용의 한글이 깨지는 현상을 방지하고, 실행 후 환경변수는 기존 값으로 복원합니다.
- `scripts/apply_update.ps1`의 UTF-8 BOM과 Windows PowerShell 파서 검사를 테스트에 추가합니다. PowerShell이 없는 비Windows 환경에서는 파서 검사만 건너뜁니다.
- 미커밋 변경 중단, 격리 worktree 검증, 보호 파일 검사, 실패 시 main 보존, 비강제 fast-forward 반영과 임시 공간 정리 흐름은 변경하지 않습니다.
- DB 스키마, 수집·Gemini 동작, 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
