# 0.10.92 발행 보조 필수 흐름·플랫폼 연결 정리

## 변경

- 발행 보조 상단 배너와 단계 카드에 Blogger 파랑, 네이버 초록, 티스토리 주황을 적용했습니다.
- 준비값 저장은 `조건부`, 전달 데이터 복사·글쓰기 편집기 열기·확장 입력·최종 확인은 `필수`로 표시했습니다.
- 개별 복사, 미리보기, 호환성 검사와 Blogger API 비공개 초안 기능은 선택 영역으로 접었습니다.
- Blogger와 네이버는 실제 새 글 편집기 주소를 저장하고 로그인 주소는 자동 처리합니다.
- 티스토리는 개인 블로그 홈 주소에서 `/manage/newpost`를 생성합니다.

## 안전 경계

- DB 스키마와 기존 프로필·초안·발행 기록은 변경하거나 삭제하지 않습니다.
- 자동 로그인, 쿠키 저장, CAPTCHA 우회와 게시 버튼 자동 클릭을 추가하지 않습니다.
- 최종 임시저장과 발행은 사용자가 직접 수행합니다.
