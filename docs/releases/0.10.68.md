# 0.10.68 보수적인 글감 기회 점수 보정 미리보기

- 사용자 글감 평가와 평가 당시 독립 근거·출처 유형·발행처 스냅샷으로 `글감 기회` 점수의 예상 조정 방향을 읽기 전용으로 표시합니다.
- 급상승을 나타내는 `트렌드 점수`는 보정 대상에서 제외하고 현재 원점수와 추천 상태를 그대로 보존합니다.
- 전체 평가 20건 이상, 같은 평가 유형 3건 이상일 때만 숫자 미리보기를 표시하며 표본이 부족하면 가감 방향과 부족한 조건만 안내합니다.
- 좋은 글감은 가점 방향, 쓸모없는 글감·잘못 묶인 주제는 감점 방향을 유지하고 근거 품질 보정이 사용자 평가 방향을 뒤집지 않게 제한합니다.
- 한 글감의 최대 조정 폭은 ±8점이며 0~100 범위를 벗어나지 않습니다.
- 현재 순위에 남아 있는 평가 글감만 미리보기에 포함하고, 순위 재계산 뒤 사라진 과거 평가 수를 별도로 구분합니다.
- 이번 버전은 `trend_clusters`, 추천 상태, 군집, 검색어와 원문을 갱신하지 않으며 실제 자동 점수 적용 기능을 추가하지 않습니다.
- DB 스키마, 외부 API 호출량, Gemini 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
