# 0.10.96 Gemini 자료 정리·군집 검토 전환

## 변경

- 자료팩 화면의 Gemini 직접 초안 생성 탭과 실행 버튼을 제거했습니다.
- 기존 `Gemini 직접 초안 생성 모델`을 `Gemini 자료 정리·군집 검토 모델`로 바꿨습니다.
- 과거 `gemini_manual_draft_model` 선택값은 읽기 호환하고 새 설정 키로 이어받습니다.
- 프로그램 군집이 먼저 실행된 뒤 별도 군집 사이의 애매한 후보만 Gemini로 묶음 검토합니다.
- 회사명만 같은 제품 출시·설비 투자·공장 증축·주가 상승·주가 하락·목표주가 전망은 각각 다른 사건으로 판정하도록 제한합니다.
- 확신도 90 이상 `same_event`만 병합하고 날짜·회차·제품·금액·주가 방향 충돌은 프로그램이 다시 차단합니다.

## 안전 경계

- Gemini 호출 중에는 DuckDB 연결을 유지하지 않습니다.
- API 키 없음, 한도 소진, 네트워크 실패, 잘못된 JSON은 기존 알고리즘 군집을 취소하지 않습니다.
- 원본 `source_items`, 기존 자료팩·초안·리비전·사실 확인·발행 기록과 DB 스키마를 변경하지 않습니다.
- 최종 초안은 검색·사실 확인 요청서를 외부 AI에 보내고 결과를 검사하는 흐름을 유지합니다.
