# 0.10.66 NAVER·Daum 검색 요청 전체 원장

- NAVER 뉴스·블로그와 Daum 웹문서·카페의 실제 검색 요청을 검색어·세부 출처·페이지 단위로 기록합니다.
- 정상 응답, 결과 0건, 최종 오류, 실제 시도 횟수, 재시도 횟수, HTTP 상태·오류 유형·소요 시간을 보존합니다.
- 검색 결과 저장이 끝난 뒤 기존 발견 원장과 연결해 요청별 신규 저장·기존 갱신·형식 또는 중복 제외 건수를 계산합니다.
- 설정의 검색어 성과 진단에서 요청 오류율, 0건 비율, 성공당 결과 수, 신규 원문 1건당 요청 수와 최근 요청 원장을 확인할 수 있습니다.
- 0.10.66 이전 수집은 실제 요청 원장이 없으므로 과거의 0건 요청과 API 오류를 역산하지 않습니다.
- 포털 네트워크 요청 중 DuckDB를 열지 않는 현재 구조와 출처별 부분 성공 규칙을 유지합니다.
- 기존 `collection_query_discoveries`와 원문·군집·평가 기록은 변경하거나 삭제하지 않습니다.
