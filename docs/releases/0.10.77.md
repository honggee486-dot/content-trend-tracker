# 0.10.77

- AI 요청서 화면에 기본 접힌 자료팩 버전 기록·비교·입력값 재사용 패널을 추가했습니다.
- 같은 주제의 작성 설정, 근거 추가·제외와 AI 요청서 줄 단위 차이를 비교합니다.
- 각 자료팩을 사용한 AI 생성 결과와 초안 연결 건수를 표시합니다.
- 과거 자료팩 설정은 세션 입력값으로만 불러오며, 사용자가 저장하기 전에는 새 자료팩을 만들지 않습니다.
- 현재 연결에서 빠진 트렌드 신호와 보관된 사실 참고 자료는 재사용 선택에서 제외하고 개수를 안내합니다.
- 기존 자료팩, 생성 세션, 초안과 당시 근거 연결은 변경하거나 삭제하지 않습니다.
