# 0.10.79

- 설정 화면에 기본 접힌 `수집 출처 다양성 진단`을 추가했습니다.
- 최근 24시간·72시간·7일의 수집 원문, 현재 순위 군집 연결률과 다중 출처 군집 비율을 읽기 전용으로 계산합니다.
- 출처별 최근 원문·군집 연결 원문·교차 출처 연결률·군집 점유율을 표시합니다.
- 자주 함께 묶이는 출처 조합과 3개 이상 출처 군집을 확인할 수 있습니다.
- 표본 부족, 낮은 다중 출처 비율, 특정 출처 편중, Google Trends 등 출처별 낮은 교차 연결을 보수적으로 안내합니다.
- 진단은 수집 설정, 분석 입력 상한, 정규화 또는 군집 기준을 자동 변경하지 않습니다.
- 새 테이블이나 마이그레이션 없이 기존 `source_items`, `trend_clusters`, `trend_cluster_items`를 읽기 전용으로 사용합니다.
