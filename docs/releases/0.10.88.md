# 0.10.88 앱 버전 표시

## 변경 목적

적용 후 현재 버전을 앱 화면에서 바로 확인할 수 없었던 불편을 해소합니다. 프로젝트 루트의 `VERSION` 파일을 단일 기준으로 사용해 모든 화면과 브라우저 탭에 버전을 표시합니다.

## 주요 변경

- 모든 화면의 상단 안내에 `현재 버전: vX.Y.Z`를 표시합니다.
- 브라우저 탭 제목에 `콘텐츠 트렌드 트래커 · vX.Y.Z`를 표시합니다.
- `src/app_version.py`에서 버전 읽기, 표시 문자열과 브라우저 제목 생성을 담당합니다.
- UTF-8 BOM과 앞뒤 공백이 있는 정상 버전 파일도 안전하게 읽습니다.
- 파일 누락, 인코딩 오류 또는 잘못된 형식은 `버전 확인 불가`로 처리합니다.

## 호환성과 안전

- DB 스키마 변경이 없습니다.
- `.env`, 실제 DuckDB와 Windows 작업 스케줄러를 변경하지 않습니다.
- Gemini 요청·응답, 수집량, 군집과 점수 계산을 변경하지 않습니다.
- 버전 파일 문제 때문에 Streamlit 앱 전체가 시작되지 않는 상황을 피합니다.

## 검증

- 정상 버전, UTF-8 BOM, 누락 파일과 잘못된 형식의 폴백을 테스트합니다.
- 모든 화면 상단 표시와 브라우저 탭 제목 연결을 정적 회귀 테스트로 확인합니다.
- 전체 pytest, Python 구문 검사와 `git diff --check`를 실행합니다.
