# 0.10.90 설정·프로필 운영 기준 정합화

## 변경 내용

- 설정 메뉴 진입 시 `기본 설정`과 기존 기본 입력값이 먼저 표시되는 현재 화면 구조를 운영 기준에 반영했습니다.
- 상단 설정 메뉴를 `기본 설정 / AI·품질 / 발행 채널 / 자동화·이력 / 데이터·연동`으로 명확히 기록했습니다.
- 관리형 추천 전략은 Blogger 3개와 네이버 1개, 실제 활성 프로필은 티스토리 1개를 포함한 5개라는 차이를 문서화했습니다.
- Blogger는 파란색, 네이버는 녹색, 티스토리는 주황색으로 구분하는 현재 UI 기준을 반영했습니다.
- WordPress, Velog, 브런치, 사용자 지정과 중복 프로필은 화면과 발행처 선택에서 제외하지만 과거 초안·발행 기록 보호를 위해 물리 삭제하지 않고 비활성 보관합니다.
- `VERSION`, `AI_CONTEXT.md`, `README.md`, `CHANGELOG.md`, 블로그 운영 문서와 다음 작업 문서를 같은 기준으로 맞췄습니다.
- 현재 문서와 릴리스 버전이 다시 어긋나지 않도록 회귀 테스트를 추가했습니다.

## 데이터 안전

- DuckDB 스키마와 실제 사용자 데이터는 변경하지 않습니다.
- 기존 프로필 ID, 초안 배정, 발행 준비, Blogger 바인딩과 발행 기록을 재작성하거나 삭제하지 않습니다.
- 자동 로그인, 쿠키 저장, CAPTCHA 우회와 무인 자동 게시를 추가하지 않습니다.
