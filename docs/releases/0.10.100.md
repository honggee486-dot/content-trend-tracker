# 0.10.100 설정 스크롤과 예약 실행 실제 상태

## 확인된 문제

설정 전용 CSS가 탭 목록뿐 아니라 `stTabs` 전체에 가로 오버플로를 적용해 긴 탭 본문의 세로 흐름까지 영향을 줄 수 있었습니다. 또한 Windows 작업 스케줄러의 준비 상태만으로는 실제 수집이 DB에 기록됐는지, 신규·갱신 자료가 있었는지, Gemini 단계가 생략됐는지 알 수 없었습니다.

## 변경

- 가로 스크롤을 탭 목록에만 적용하고 탭 본문은 세로로 자연스럽게 확장합니다.
- 설정 화면에 하단 여백을 추가해 긴 폼과 표의 마지막 항목까지 이동할 수 있게 합니다.
- 예약 실행 화면에 최근 `background_refresh`의 실제 DB 상태와 출처별 상세를 표시합니다.
- 신규·갱신 0건과 Gemini 단계 생략이 정상일 수 있는 조건을 안내합니다.

## 안전 경계

수집·순위·Gemini 실행 규칙과 Windows 작업 등록 방식은 변경하지 않습니다. 기존 `collection_runs`와 `collection_run_sources`를 조회만 하며 DB 스키마, 원본 데이터, 자료팩, 초안, 사실 확인과 발행 기록을 변경하지 않습니다.
