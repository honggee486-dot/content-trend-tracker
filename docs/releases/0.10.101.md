# 0.10.101 군집 대표 제목 반복 모델명 정리

## 변경

- 숫자가 포함된 동일 모델 토큰의 반복과 한두 글자 차이의 포함 관계를 대표 제목 후보에서 감점합니다.
- `삼성전자 갤럭시 z폴드8 울트라 폴드8 플립8` 같은 키워드 나열형 검색어보다 `갤럭시 Z 폴드8·플립8 사전 판매 144만 대 달성`처럼 사건을 설명하는 원문 제목을 우선합니다.
- 정상적인 서로 다른 모델 비교는 반복으로 처리하지 않습니다.
- 순위 알고리즘 버전을 17로 갱신해 다음 재계산에서 대표 제목을 새 기준으로 다시 선택합니다.

## 안전 경계

- 군집 병합·분리와 원문 연결은 변경하지 않습니다.
- Gemini 군집 검토 모델·후보 수·확신도 기준을 변경하지 않습니다.
- DB 스키마, 원본 자료, 자료팩, 초안, 사실 확인과 발행 기록을 변경하지 않습니다.
