# 0.10.62 시점 의존 글감 사실 참고 자료 안전 차단

- 현재 순위·경기 결과·일정·환율·주가·가격·날씨·마감·재고처럼 현재값 자체가 핵심인 주제는 선택한 사실 참고 자료가 없으면 AI 요청서와 자료팩 생성을 차단합니다.
- `오늘`·`최신`처럼 일반적인 최신성 표현만 있는 글감은 과도하게 차단하지 않고 기존처럼 웹 검색과 공식 출처 확인 규칙을 요청서에 포함합니다.
- 스포츠 문맥이 없는 `블로그 검색 순위 올리는 법` 같은 일반 검색 순위 조언은 실시간 스포츠 순위로 오인하지 않습니다.
- 사실 참고 자료를 선택하면 시점 의존 주제도 정상 생성하며, 기준일·공식 출처 확인과 일반론 대체 금지 규칙을 유지합니다.
- 새 글감 바로 입력에서 차단 대상이 감지되면 내부 주제를 먼저 만들지 않고, 주제·트렌드에서 참고 자료를 등록하도록 안내합니다.
- DB 스키마, 기존 자료팩·초안·참고 자료, Gemini 글감 25개 제한과 240분 스케줄러 설정은 변경하지 않습니다.
