# 0.10.73 Gemini 생성 안정성·설정 추천

- 설정 화면에 최근 Gemini 글감 분석 기록을 종합한 읽기 전용 안정성 추천을 추가합니다.
- 최근 최대 10회·30회 실행의 요청 글감, 저장 글감, 저장률, 부분 성공·실패, API 시도·재시도와 평균 소요 시간을 표시합니다.
- 같은 실행 구간의 `trend_topic_angle_batch_v1` 호출에서 응답 검증 실패, 평균·최대 생성 토큰과 65,000토큰 이상 근접 횟수를 계산합니다.
- 처리량 추천은 `30개 유지`, `25개로 낮추기 권장`, `20개로 낮추기 권장` 중 하나로 표시합니다.
- 완료 실행 3회·요청 글감 60개 미만이면 표본 부족으로 판정하고 현재 30개 설정을 유지합니다.
- 저장률 저하, 부분 성공·실패, 검증 실패와 토큰 근접이 반복될 때만 처리량 축소를 권장합니다.
- 사고 수준은 `medium 유지`를 기본 권고하며 현재 기록만으로 처리량 효과와 사고 수준 효과를 분리하지 않습니다.
- 모델, 요청당 처리량과 사고 수준을 자동으로 변경하지 않습니다.
- Gemini 직접 초안 생성은 추천 계산에서 제외하며 외부 API를 추가 호출하지 않습니다.
- 기존 `collection_runs`, `collection_run_sources`, `gemini_api_calls`만 읽고 DB 스키마, 수집, 점수, 초안·사실 확인·발행 기록을 변경하지 않습니다.
- Gemini 30개 상한, 기본 동시 요청 1개, 글감 기회 50점과 240분 스케줄러는 유지합니다.
