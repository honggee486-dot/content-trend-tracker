# 0.10.59 수집 이력 Gemini 결과 필터

- 최근 수집 실행 30건을 실행 유형, 전체 상태, Gemini 결과로 필터링할 수 있습니다.
- Gemini 결과는 저장 완료, 부분 저장·실패, 새 분석 없음·API 키 없음, 기록 없음으로 구분합니다.
- 실행 목록에 요청 대비 실제 저장 글감 수를 바로 보여주는 `Gemini 저장` 열을 추가합니다.
- 필터된 실행만 상세 선택 후보로 표시하고, 선택한 실행의 출처별 처리 결과와 오류 요약은 기존대로 유지합니다.
- 최근 30건의 출처별 결과는 한 번의 조회로 묶어 읽으며 DB 스키마나 외부 API 호출은 변경하지 않습니다.
