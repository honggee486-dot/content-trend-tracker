# 0.10.74 작업 대기열 근거 보기·발행 기록 관리

- 콘텐츠 작업 대기열의 `AI 요청서 준비` 항목 아래에 `수집 근거 보기`를 추가합니다.
- 근거 영역은 기본 접힘이며, 연결 트렌드 신호 전체 개수와 최근 항목 최대 8개를 표시합니다.
- 트렌드 신호의 출처·제목·게시 또는 관측 시각·신호값·포착 횟수·URL을 읽기 전용으로 확인합니다.
- 사용자가 추가한 사실 참고 자료의 종류·제목·발행처·게시일·메모·URL을 별도 표로 표시합니다.
- 발행 보조 화면 하단에 발행 기록 검색·정정·보관·복원 기능을 추가합니다.
- 플랫폼·글쓰기 URL·발행 URL·메모·발행 시각을 정정할 수 있으며 정정 사유를 필수로 남깁니다.
- 발행 기록은 물리 삭제하지 않고 `archived_at`으로 보관하며, 보관 기록은 일반 목록·중복 판정·발행 완료 준비도에서 제외합니다.
- 보관 기록을 복원하면 다시 활성 발행 기록으로 계산하고 주제 상태를 발행 완료로 복구합니다.
- 정정·보관·복원 전후 값과 사유를 `publish_record_history`에 보존합니다.
- 기존 `publish_records`에는 `updated_at`, `archived_at`만 추가하며 기존 행과 상태값을 보존합니다.
- 기존 수집·군집·Gemini·자료팩·초안·사실 확인·백업·복구 흐름은 변경하지 않습니다.
