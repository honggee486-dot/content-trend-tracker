# 0.10.99 AI 군집 검토 동점 정렬 수정

## 확인된 문제

실제 순위 재계산에서 Gemini가 둘 이상의 군집 후보에 같은 확신도를 반환했습니다. 기존 코드는 `(확신도, 후보 dict)` 튜플 전체를 역순 정렬해 확신도가 같을 때 Python이 두 `dict`를 비교했고, `'<` not supported between instances of 'dict' and 'dict'` 오류로 계산이 중단됐습니다.

## 변경

- 병합 적용 후보의 정렬 키를 확신도 내림차순과 `pair_id` 오름차순으로 명시했습니다.
- 동일 확신도의 후보 두 개가 함께 적용되는 회귀 테스트를 추가했습니다.
- 기존 확신도 90 이상 병합 기준과 날짜·회차·제품·금액·주가 방향 충돌 검사는 유지합니다.

## 데이터 안전

오류는 분석 결과를 DB에 반영하기 전 계산 단계에서 발생했습니다. 기존 `trend_clusters`, `trend_cluster_items`, 원본 `source_items`, 자료팩, 초안, 사실 확인과 발행 기록은 변경되지 않습니다. DB 스키마와 Gemini API 사용 정책도 변경하지 않습니다.
