# 0.10.71 Gemini 글감 30개·현재 문서 정합성

- 자동·예약 Gemini 글감 분석의 요청당 기본값과 허용 상한을 25개에서 30개로 조정합니다.
- 동시 요청 기본값은 1개를 유지하므로 기본 실행 한 번에 최대 30개 글감을 한 요청으로 처리합니다.
- `GEMINI_TOPIC_ANGLE_ITEMS_PER_REQUEST`와 호환 설정값이 30을 넘으면 프로그램에서 30으로 제한합니다.
- `.env.example`, README, AI_CONTEXT와 회귀 테스트를 현재 30개 운영 기준으로 맞춥니다.
- 설정 화면의 요청당 최대·동시 요청·버튼 1회 최대 계산은 그대로 사용하고, 과거 “100개를 1회 요청” 고정 설명은 현재 설정값 기준 안내로 바꿉니다.
- 저장되지 않은 후보는 삭제하지 않고 다음 실행 대상으로 유지합니다.
- Gemini 글감 분석 사고 수준 `medium`, 생성 토큰 65,000 경고, 글감 기회 50점 기준과 240분 스케줄러는 유지합니다.
- DB 스키마, 출처 수집, 점수, 초안·사실 확인·발행 기록은 변경하지 않습니다.
