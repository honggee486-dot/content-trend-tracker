# 콘텐츠 감독형 반자동 제작 목표

## 목표

`content-trend-tracker`의 장기 사용 방식은 사용자가 각 제작 단계를 직접 반복하는 도구가 아니라,
프로그램이 수집·분석·작성·검증·발행 준비를 대부분 수행하고 사용자는 핵심 판단과 최종 공개만 맡는
**감독형 반자동 콘텐츠 제작 시스템**으로 한다.

사용자의 정상 작업은 가능한 한 다음 흐름에 수렴한다.

```text
대시보드
→ 추천 글감 목록에서 주제 선택
→ 검증 점수 1순위 주제 방향이 기본 선택됨
→ 자동/수동 작성 추천 확인
→ 필요하면 주제 방향 또는 작성 방식만 변경
→ 요청서 생성
→ 자동 작성이면 구독형 Agent 우선, 사용 불가 시 설정한 0원 API 1~4순위 fallback
→ 수동 작성이면 기존 ChatGPT 전달 흐름
→ AI JSON 형식·출처·사실 확인 검사
→ 초안 자동 저장
→ 대상 블로그 자동 배정
→ 플랫폼별 임시저장 또는 안전한 발행 준비
→ 사용자가 최종 글 확인
→ 발행 또는 삭제/보류
```

## 사용자가 맡는 일

정상 케이스에서 사용자의 반복 작업은 다음 네 가지를 중심으로 줄인다.

1. 대시보드의 추천 글감 중 실제로 쓸 주제 선택
2. 기본 선택된 1순위 주제 방향을 그대로 쓰거나 다른 방향 선택
3. 자동/수동 작성 추천을 그대로 쓰거나 반대로 선택
4. 플랫폼에 준비된 최종 글을 확인해 발행·수정·삭제·보류 판단

자료 수집, 정규화, 군집, 글감 평가, 근거 정리, 기본 방향 선정, 요청서 작성,
AI 결과 검사, 반복 사실 확인, 초안 저장, 블로그 배정과 플랫폼별 준비는 프로그램이 가능한 범위에서 처리한다.

## 자동화 경계

자동화 수준을 높여도 다음 안전 경계는 유지한다.

- 자동 로그인 금지
- 브라우저 쿠키·세션 토큰·프로필 직접 수집/저장 금지
- CAPTCHA 우회 금지
- 사용자 승인 없는 최종 공개 게시 금지
- 실제 비용이 발생할 수 있는 AI 모델의 자동 사용 금지
- 플랫폼이 공식적으로 지원하지 않는 비공개 작성 API를 추측해 사용하지 않음

플랫폼별 `임시저장`은 공식 API 또는 현재 프로젝트의 안전한 사용자 보조 방식으로 가능한지 먼저 확인한다.
지원되지 않는 플랫폼에서는 편집기 입력 준비까지 자동화하고 최종 저장/공개는 사용자가 수행한다.

## 단계별 구현 순서

### 1. 감독 의사결정 계층

- 주제 방향 생성과 동시에 `auto` / `manual` 작성 추천 저장
- 애매하거나 판정이 없는 경우 `manual` 기본
- 검증 점수가 가장 높은 주제 방향을 기본 선택
- AI 요청서 화면에서 추천 이유와 작성 방식을 확인하고 사용자가 override 가능

### 2. 자동 작성 실행 계층

- ChatGPT 계정으로 공식 로그인된 Codex/Agent 실행 경로를 기본 자동 작성 엔진으로 검토
- 프로그램이 로그인 원본 데이터나 브라우저 쿠키를 읽지 않음
- Agent 사용 불가·한도 소진 시 설정된 0원 API 1~4순위를 순서대로 사용
- 각 호출 직전 0원 여부를 다시 확인하고 첫 성공에서 즉시 종료
- 네 모델이 모두 실패하면 요청서를 보존하고 수동 작성으로 종료

### 3. 자동 검사·초안 저장 계층

- 자동 응답도 수동 붙여넣기와 동일한 기존 AI JSON 검사기를 통과
- 형식·출처 검사를 통과한 결과만 generation session과 draft로 저장
- 사실 확인 실패는 다른 모델을 무한 재호출하는 대신 재검색·주장 완화·수동 확인 상태로 분리
- 자동 실패 시 기존 요청서·자료팩·사용자 편집 데이터를 보존

### 4. 블로그별 임시저장/발행 준비 계층

- 기존 블로그 추천·배정 결과를 사용해 대상 프로필 자동 선택
- Blogger, Tistory, Naver Blog를 플랫폼별 공식 기능과 정책에 따라 분리
- 공식 임시저장 API가 안전하게 지원되는 경우에만 자동 임시저장
- 그렇지 않으면 제목·본문·태그·이미지·카테고리·링크를 편집기에 옮기기 쉬운 상태까지 준비
- 사용자가 실제 공개 전에 최종 글을 보고 발행·수정·삭제·보류

## 현재 구현 상태

- 콘텐츠 작업 대기열과 추천 글감/주제 방향 흐름이 이미 존재한다.
- 주제 방향은 검증된 하위 점수 합계로 다시 정렬되어 1순위가 기본 방향으로 사용된다.
- 자동 작성용 현재 0원 모델 카탈로그, 1시간 lazy refresh, 성능 데이터 24시간 lazy refresh,
  사용자 지정 1~4순위 fallback 설정이 존재한다.
- 이번 단계에서 주제 방향 생성 요청에 자동/수동 작성 추천을 추가하고,
  기존 판정이 없는 자료는 수동 추천으로 안전하게 처리한다.
- 실제 자동 작성 실행과 플랫폼 임시저장 연결은 후속 단계다.

## 완료 기준

장기 목표의 완료 상태는 사용자가 일반적인 글 한 편을 만들 때 다음이 성립하는 것이다.

- 대시보드 밖의 여러 제작 화면을 순서대로 찾아다닐 필요가 없음
- 추천 주제와 기본 방향을 확인한 뒤 최소한의 선택만 하면 됨
- 자동 작성 성공 시 수동 복사/붙여넣기가 필요 없음
- 검증된 초안이 자동으로 적절한 블로그의 임시저장/발행 준비 상태까지 이동함
- 사용자는 최종 글을 보고 발행하거나 삭제/보류하는 결정에 집중함
- 실패·비용·검증 불확실성은 자동으로 다음 안전 상태로 전환되고 데이터가 보존됨
