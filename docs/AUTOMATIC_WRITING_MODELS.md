# 자동 작성 모델 라우팅

## 목적

자동 작성용 외부 모델은 유료 fallback을 사용하지 않는다. OpenRouter, Groq Free,
OpenCode Zen에서 현재 비용이 0원으로 확인되는 모델만 후보로 관리하고 사용자가 정한
최대 4개 우선순위를 그대로 실행한다.

## 모델 목록 갱신

모델 목록 갱신은 타이머나 예약 작업이 아니다.

- 마지막 전체 모델 API 확인 후 1시간이 지나지 않았으면 저장된 목록을 재사용한다.
- 1시간이 지난 뒤 모델 목록이 필요한 시점에는 OpenRouter, Groq, OpenCode Zen의
  현재 모델 목록을 한 번씩 다시 확인한다.
- 설정 화면의 `전체 모델 로드`는 1시간이 지나지 않아도 강제 새로고침한다.
- 한 Provider 조회가 실패하면 다른 Provider 결과를 취소하지 않고 해당 Provider의
  이전 정상 목록을 stale 상태로 보존한다.

자동 작성 모델 목록에는 이름에 `free`가 들어간 모델만 넣지 않는다.

- OpenRouter는 현재 Models API의 prompt/completion 및 실제 텍스트 호출에 영향을
  주는 가격 필드가 0인지 확인한다. 이벤트로 가격이 0이 된 일반 모델도 포함한다.
- Groq는 `GROQ_PLAN=free` 확인과 현재 활성 모델 목록을 함께 사용한다.
- OpenCode Zen은 현재 모델 목록과 공식 Zen 가격표를 교차 확인해 입력·출력이
  모두 Free인 모델만 포함한다.

## 성능 데이터

모델 성능 데이터도 예약 작업으로 갱신하지 않는다.

- 마지막 정상 성능 갱신 후 24시간 이내면 저장된 성능 데이터를 사용한다.
- 24시간이 지난 뒤 성능 데이터가 필요한 시점에 사용자가 저장한 자동 작성
  1~4순위를 순서대로 이용해 성능 갱신 요청을 보낸다.
- 각 실제 생성 호출 직전에는 그 모델이 여전히 0원인지 다시 확인한다.
- 첫 성공에서 즉시 종료하며 다음 모델은 호출하지 않는다.
- 모두 실패하거나 응답 검증에 실패하면 이전 정상 성능 데이터를 그대로 유지한다.
- 성능 데이터 갱신은 Git 파일이나 브랜치를 수정하지 않고 DuckDB `app_settings`
  캐시에만 저장한다.

평가 축은 AI Workflow Helper의 task-aware 방식에서 블로그 자동 작성에 필요한
부분을 재사용한다.

1. 글쓰기
2. 분석/추론
3. 지시준수
4. 위 세 축의 종합값

화면 전체 목록은 글쓰기 → 분석/추론 → 지시준수 → 종합 순으로 정렬한다.
근거가 부족한 새 모델은 임의 점수를 만들지 않고 `미평가`로 남겨 목록 아래쪽에
표시한다. 알려진 일부 모델은 AI Workflow Helper의 검토된 점수를 초기 기준으로
사용하지만 이후 런타임 성능 갱신 결과는 Git을 변경하지 않고 별도로 저장한다.

## 사용자 우선순위

설정 화면에서 최대 4개 모델을 순서대로 저장한다.

`1순위 → 2순위 → 3순위 → 4순위`

- 사용자가 저장한 순서는 앱 재시작 후에도 유지한다.
- 전체 모델 목록이나 성능 데이터를 새로 받아도 저장 순서를 자동으로 바꾸지 않는다.
- 현재 목록에서 사라진 모델은 임의 교체하지 않고 현재 목록 없음으로 표시한다.
- 실행 중 첫 성공에서 종료한다.
- 네 모델이 모두 실패하면 자동 경로를 종료한다.
- 유료 모델이나 비용을 확인할 수 없는 모델로 자동 전환하지 않는다.

## 비용 안전 게이트

저장된 목록에서 0원으로 보이더라도 실제 생성 요청 직전에 Provider별 현재 상태를
다시 확인한다.

- 현재 0원 확인: 호출 가능
- 유료로 변경됨: 호출하지 않고 다음 순위
- 가격/Free 플랜 확인 실패: 호출하지 않고 다음 순위
- 모델 삭제/비활성: 호출하지 않고 다음 순위

OpenRouter 크레딧이 계정에 남아 있어도 이 자동 fallback은 가격이 0이 아닌 모델을
호출하지 않는다.

## 인증정보

API 키는 저장된 모델 카탈로그·성능 캐시에 넣지 않는다. 로컬 `.env`의 다음 값만
읽는다.

- `OPENROUTER_API_KEY`
- `GROQ_API_KEY`
- `GROQ_PLAN=free`
- `OPENCODE_API_KEY`

실제 키 값은 Git에 커밋하지 않는다.
